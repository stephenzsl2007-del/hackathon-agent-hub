# 息屿 · 桌面花园使用说明

双击 [息屿.app](/Users/amireux/Documents/ChatGPT/ee黑客松/息屿.app) 启动。当前交付是 macOS Apple Silicon 桌面应用。文件堆肥、透明窗口、系统菜单和鼠标穿透都应在这个应用里体验。

完整路径：`/Users/amireux/Documents/ChatGPT/ee黑客松/息屿.app`

## 先找到花园的入口

花园默认出现在当前显示器工作区的右下方。系统菜单栏中的像素幼苗图标，以及小岛上的右键菜单，都可以打开主要功能。

| 想做什么 | 怎么操作 |
| --- | --- |
| 找回花园、恢复交互 | 菜单栏「找回花园与工具」，或 `⌘⌥⇧G` |
| 进入文件投喂模式 | 菜单栏「进入文件投喂模式」，或 `⌘⌥⇧F` |
| 打开临时工具条 | 菜单栏「花园工具」；花园获得焦点时也可按 `H` |
| 移动花园 | 右键选择「移动花园（拖动模式）」，然后拖动；完成后再选一次或按 `Esc` |
| 调整大小或找回位置 | 菜单「调整位置与大小」，选择放大、缩小或恢复默认位置 |
| 保持在其他应用上方 | 菜单「保持置顶」 |
| 临时收起花园 | 菜单「隐藏花园」；再通过菜单显示 |
| 让所有鼠标操作穿过花园 | 菜单「完全鼠标穿透」；通过菜单栏或 `⌘⌥⇧G` 恢复 |
| 退出 | 菜单「完全退出息屿」，或花园获得焦点时按 `⌘Q` |

这里的 `⌥` 是 Option 键。完全穿透时不能直接点击或拖文件到花园，先用投喂快捷键或菜单恢复接收文件的区域。

## 让植物长大

打开工具条，选择「播种」。选种下拉框可以选择 24 种植物，包括树木、花卉、果蔬、灌木和菌菇。选择后点击岛屿中央的种植草地；睡莲需要种在池塘里。已有植物附近需要留一点空隙。

选择「落雨」并在种植区按住，给植物浇水。植物使用五张不同的阶段素材，依次出现萌芽、幼苗、进一步生长、花苞或幼果、开花或成熟等变化。不同类别的视觉表现有所区别。阶段、成长进度和浇水状态会保存。

植物的日常进度随花园运行推进，浇水会加快成长。当前隐藏花园或关闭应用后，植物不会补算离线成长；重新打开后从存下的进度继续。

想快速看完五个阶段，可点「小小奇迹」。约 26 秒的演示会标出当前阶段，最后展示夜色与萤火；结束后恢复演示前的日常植物布局。演示回放本身不消耗饲料和水。用「结束」或 `Esc` 可以提前返回。

## 整理文件，给团团准备点心

1. 点击场景里的堆肥箱，或进入文件投喂模式。
2. 拖入你明确准备回收的文件，也可以点击面板中的选择文件按钮。
3. 检查本批清单。确认后，文件才会真正移入系统废纸篓；关闭或取消不会回收文件。
4. 每个成功回收的文件获得 1 份饲料，失败项目单独显示原因，文件大小不影响奖励。
5. 点击「投放 1 份饲料到草地」。小动物靠近食物，团团的饱食度最多增加 18，最高为 100；已经吃饱时会保留饲料。

「打开废纸篓」会打开系统废纸篓。需要恢复文件时，使用 macOS 自己的恢复操作。应用没有直接“吐回文件”的按钮。

首版一次最多接收 30 个普通文件，不接收文件夹、应用、符号链接和受保护目录中的文件。它不会自动查找或清理电脑里的其他文件，也不会读取文件正文。

团团的饱食度约每小时减少 2。陪伴时间与进食共同决定成长，至少经过 3 天才可能进入成长期，至少经过 7 天才可能成年；连续投喂不能跳过真实天数。忘记投喂不会让它死亡，也不会清空陪伴记录。

## 专注一会儿，收集浇花水

点击场景里的长椅，或在菜单中选择「专注陪伴」。可以选 25、10、5 分钟，或「1 分钟 · 快速体验」，然后主动开始。

在面板的「随手记一点」中输入，会产生短暂的键盘雨。当前只响应息屿应用内的键盘活动；切换到其他应用工作时，专注计时照常继续，但不会感知其他应用的打字。输入文字不进入存档，随手记也只在本次打开时保留。

不打字、阅读和思考都不会中断计时。可以暂停、继续或取消。完成一段专注后获得 3 滴水，每段只发放一次；提前取消没有奖励。点「用 1 滴水浇花」即可把奖励用在花园里。落雨工具也可直接体验浇水。

应用重启后，未结束的专注以暂停状态恢复，需要手动继续；关闭应用期间不会直接获得完成奖励。

## 把声音变成风

点击风车，或工具条中的「吹一口气」。允许麦克风后，先安静约 1 秒完成环境声校准，再轻轻吹气或发出声音。草叶、风车、花瓣和飘散的种子会响应风力，声音停止后风逐渐减弱。

再次点击麦克风入口会停止采集，也可以在等待授权时取消。原始音频只在本机分析，不录音、不上传、不进入存档。当前算法使用声音强弱与持续时间，普通说话和环境噪声也可能引起风，不能准确区分“吹气”。

不使用麦克风时，选择「送风」并按住小岛，或在花园获得焦点且没有输入文字时按住空格。声景默认关闭，可以在工具中主动开启轻柔的风声和音符。

## 和小生灵、朋友一起玩

场景已接入猫、狗、鸟、松鼠、兔子和鸭子六类动物。它们有闲逛、停留和接近食物等简单行为，点击动物也会得到短反馈。光标停在草地上片刻，可以等蝴蝶靠近。

轻点池塘会出现水波。「潮汐」工具允许上下拖动或使用滑杆调整水位；`N` 或昼夜按钮可切换夜景与萤火。

菜单中的「邀请手机加入」会显示二维码。电脑和手机连接同一个 Wi-Fi 后，朋友可以用手机触控参与风、雨、播种、潮汐和萤火等互动。手机端没有电脑的文件回收与窗口权限。若现场 Wi-Fi 隔离设备，可尝试让电脑和手机连接同一个手机热点；这项联机体验依赖现场网络。

花园获得焦点、没有在输入框中打字且未打开面板时，可用 `1–6` 切换漫游、送风、落雨、播种、投喂和潮汐；`M` 开关麦克风，`N` 切换昼夜，`H` 显示或收起工具。

## 约 90 秒展示流程

提前准备一个专门用于演示、可以回收的普通测试文件。把桌面背景切成便于辨认透明边缘的画面，确认团团还没有吃饱。

| 时间 | 操作与讲述 |
| --- | --- |
| 0–8 秒 | 展示桌面上的花园。打开专注面板，启动「1 分钟 · 快速体验」，在随手记中输入几个字展示轻雨，然后关闭面板。 |
| 8–25 秒 | 点击动物。拖入测试文件，展示清单，确认回收，再投放 1 份饲料；指出真实文件回收与动物饱食度的对应关系。 |
| 25–35 秒 | 展示风车和叶片响应。麦克风尚未完成实体测试时，直接用「送风」或空格，明确说是手动送风。 |
| 35–63 秒 | 点「小小奇迹」，展示五张不同的植物阶段素材和夜景，等待演示返回日常花园。 |
| 63–76 秒 | 等 1 分钟专注真正结束，展示新增的 3 滴水，再使用 1 滴水浇花。 |
| 76–90 秒 | 从菜单切换完全穿透，尝试操作花园后方的测试窗口，再用 `⌘⌥⇧G` 找回花园。此步骤同时是现场验收，未经实际操作不要宣称通过。 |

演示中的快速植物生长属于明确标识的展示模式。1 分钟专注仍等待真实的一分钟，没有提前发放完成奖励。
