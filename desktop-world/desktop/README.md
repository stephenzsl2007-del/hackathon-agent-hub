# 息屿：原生桌面能力

Windows 的构建、快捷键与实机验收见 [Windows 说明](../docs/WINDOWS.md)。下面涉及 `.app`、`~/.Trash` 的部分专指 macOS。

项目上级目录中的 `息屿.app` 是可直接双击运行的 macOS Apple Silicon 应用。开发时也可以双击 `start.command`；它优先使用已安装的 Electron 运行当前源码。打包命令 `node desktop/package.cjs` 会更新上级目录的应用。

## 桌面入口

默认打开真正透明、无边框、无窗口阴影的原生窗口。长岛舞台默认使用所在显示器工作区约 58% 宽，最小 560×360，并靠右下放置；尺寸受工作区约束。页面和场景的透明度由渲染层保持；原生窗口不使用壁纸截图。

原生产品始终保持透明桌面形态，不提供传统完整窗口的切换入口。

系统菜单栏的像素幼苗图标提供完整操作，场景右键菜单使用同一组操作：

| 操作 | 入口 |
| --- | --- |
| 显示／隐藏花园 | 托盘菜单；显示不会主动获取输入焦点 |
| 置顶开关 | 托盘「保持置顶」 |
| 交互模式／完全穿透 | 托盘相应选项 |
| 从完全穿透中找回 | `⌘⌥⇧G`，或托盘「找回花园与工具」 |
| 文件投喂模式 | `⌘⌥⇧F`，或托盘「进入文件投喂模式」 |
| 移动 | 漫游时直接拖动小岛、动物或道具；也可拖左侧小手柄，或按住 Option 拖动 |
| 缩放／恢复位置 | 托盘「调整位置与大小」 |
| 结束投喂／移动 | `Escape`，或再次选择同一托盘操作 |
| 完全退出 | 托盘「完全退出息屿」，或 `⌘Q` |

托盘和场景右键菜单还可以切换白天／夜色、环境音、麦克风送风，以及启动独立的五阶段成长演示。Windows 对应组合为 `Ctrl+Alt+Shift+G/F`；macOS 使用额外的 Option 键，避免占用 Finder 的 `⌘⇧G`。

macOS 交互模式由渲染层命中测试请求原生 `setIgnoreMouseEvents(..., { forward: true })` 切换透明区域穿透。Windows 默认保持交互，避免悬停穿透误将点击交给下层窗口；透明空白也会接收鼠标。CSS `pointer-events` 不承担系统穿透。主动开启完全穿透后不接受场景点击，但保留托盘和全局恢复快捷键。投喂模式会临时关闭穿透并置顶，结束后恢复用户的置顶和鼠标模式设置。

位置、尺寸、置顶、鼠标模式在停止变化 500 毫秒后保存。显示器移除、连接或工作区变化后会重新约束边界，避免花园留在不可见屏幕。代码具备此处理，但物理多显示器插拔仍需现场验证。

普通轻点仍触发动物、池塘或道具互动；移动超过 5 个屏幕逻辑像素才开始搬动小岛。播种、落雨等工具保留原玩法，Option／Alt 或专用手柄仍可搬动。面板打开时暂停拖岛，关闭面板后恢复。跨显示器拖动途中允许花园横跨两个屏幕，松手后收回指针所在显示器的工作区；单屏边界限制不变。Windows 从拖动阈值开始以系统指针绝对坐标更新位置，保留固定逻辑尺寸，避免分数缩放下的累计变大；其他平台串行发送位置增量。最终位置在拖动结束后保存，取消、失去焦点、隐藏或锁屏都会结束拖动。

本分支窗口布局使用 `layoutVersion: 4`，对应长岛 `640×280` 视口。例如 `1728×1002` 工作区默认得到 `1002×440` 窗口。旧版宽度仍达到工作区 65% 的大型舞台，只收缩一次至原宽的约 82%，保持右下角锚点；旧圆岛窗口一次性缩短到长岛高度，上游 `layoutVersion: 2` 的紧凑长岛保留原尺寸。同时保留位置锚点、键盘雨及置顶偏好。窗口迁移只写 `window-state.json`；世界存档另由场景适配保留植物和资源。手动调整时通常最小为 `560×360`；工作区更小时以实际可用区域为上限。

Windows 分数 DPI 移动时 Canvas 仅在实际尺寸变化时重设缓冲区，并在同次 resize 中补画，避免等待下一帧期间出现空白闪烁。

## 文件回收边界

原生 preload 只接收用户拖入的真实 `File`，用 Electron `webUtils.getPathForFile` 取得路径。页面不能传入任意路径调用回收。

`prepareFiles(files)` 返回有效期 5 分钟的批次与逐项清单，不移动文件。界面展示清单后，用户确认才调用 `confirmTrash(batchId)`。原生端再次核对文件设备、inode、大小、修改时间及真实路径，然后调用系统 `shell.trashItem`。只在成功后返回 1 份饲料奖励；大小不影响奖励。重复批次、并行重复确认、失败项、取消项均不会重复奖励。

首版只接受普通可写文件。文件夹、应用、符号链接、系统目录、用户 Library、废纸篓、应用本身与存档目录都会拒绝。不会扫描未被选择的文件，也不会读取文件正文。

`openTrash()` 打开系统废纸篓。没有提供未经验证的直接恢复按钮；用户可以使用系统自己的恢复操作。

## 统一存档

原生主进程是磁盘存档的唯一写入方。文件位于 Electron 的 `app.getPath('userData')`：

- `garden-state.json`：日常花园、动物、资源、专注与用户设置快照。
- `demo-state.json`：独立演示快照，使用 `slot: 'demo'` 访问。
- `window-state.json`：原生窗口位置和模式。

`loadState()` 返回状态、版本与最后保存时间。`saveState(snapshot)` 合并 500 毫秒内的请求，完成临时文件写入、同步和原子替换后，才返回 `{ ok: true, revision, savedAt }`。保存失败保留原文件并返回明确错误。最近一次有效版本保存在 `.bak`；主文件损坏时尝试备份，同时保留损坏文件。

正常退出先向渲染层发送带请求 ID 的 `prepare-quit` 命令。渲染层完成最终保存后用 `ackQuit(requestId, saved)` 确认；主进程随后刷新所有待写入状态再退出。保存失败或 3 秒未收到确认时，提供重试、返回花园和仍然退出三个选项。Alt+F4 与托盘退出使用同一流程。

不接收媒体数据作为功能输入，不持久化麦克风原始音频或键盘内容。当前架构仍是单个渲染窗口负责游戏规则、主进程负责受控持久化，并未声称已经实现架构文档中计划的 utilityProcess 世界服务。

## 权限和联机

麦克风仅允许本机应用页面申请音频权限，不开放摄像头权限；打包的 Info.plist 包含用途说明。锁屏／休眠向渲染层发送 suspend 命令，由音频模块释放采集。

Windows 右键菜单可开启「后台键盘雨」。独立原生助手只传递敲键发生的存在信号，每 250 毫秒最多一次；不读取键值、文字、应用名或窗口标题。开关偏好保存在本机；关闭、隐藏花园、锁屏或休眠时停止助手，重新显示／解锁后仅恢复先前开启的状态。助手异常会关闭开关并提示。macOS 和浏览器保留应用内键盘雨。全局快捷键仍只用于找回和投喂。

「平行桌面」只监看用户明确关联的本机普通文件夹，不递归扫描。`太阳.txt`、`风.txt`、`雨.txt` 的存在改变昼夜或天气；PNG/JPG/WebP/BMP 图片可成为最多 8 名访客，每张源文件上限 10 MB，缩略图在本地生成。不会读取其他文件正文、上传、删除或移动原文件。「创建互动文件夹」使用新的独立目录，重名时另取名称，不覆盖旧目录；断开关联或退出即停止监看。

桌面本地服务默认使用端口 4178，网页开发服务使用 4177。手机连接同一 Wi-Fi 后可扫描邀请二维码，用触控控制六种环境互动。手机不会获得文件、存档、窗口权限，也不需要麦克风权限。

## 已运行的定向验证

- `node --test tests/native-services.test.cjs`：存档合并与恢复、写入失败保留旧数据、取消回收、确认前文件变化、符号链接及保护目录拒绝、原生操作失败、重复确认零重复奖励；退出握手等待、错误请求 ID 拒绝和无响应超时。
- `node --test tests/island-drag.test.mjs tests/native-window.test.cjs tests/window-layout.test.cjs`：轻点和拖动区分、工具／面板隔离、取消清理、原生调用排序、跨屏小步移动、负坐标显示器、屏幕间空洞保护、Windows 绝对坐标拖动、重复拖动时分数 DPI 尺寸稳定、Windows 控件不被自动穿透、主动穿透与 macOS 原行为保留、最终位置合并保存和旧圆岛到长岛的窗口迁移。原生窗口测试使用真实主进程源码及 Electron stub，不启动另一个应用。
- `node --test tests/keyboard-activity.test.cjs tests/parallel-folder.test.cjs`：键盘雨开关与睡眠清理、仅存在信号的协议校验、文件夹监听、断开后的过期结果忽略、图片限制与不覆盖原文件。
- `tests/verify-native-trash.cjs`：用 Electron `shell.trashItem` 处理专门创建的可丢弃测试文件；确认原路径消失，真实 `~/.Trash` 中的文件存在、大小和内容一致，重复请求奖励为 0。实际结果保存在 `tests/native-trash-verification.json`。

透明画面、真实桌面穿透、托盘操作、麦克风实体输入与显示器热插拔属于原生 UI／设备验收，不能用以上文件测试替代。以项目最终验收记录为准。

需要定位实体拖动时，可临时在 `app.getPath('userData')` 创建空文件 `drag-debug.enabled`，再完全退出并重新启动应用；也支持启动参数 `--xiyu-drag-debug`。诊断只在本机 `drag-debug.json` 保留最后 500 条事件，包括固定的指针坐标、命中／面板状态、捕获和移动结果；不接收任意文字、文件路径或键盘内容。默认关闭。验收后删除标记和日志并重启即可关闭。
